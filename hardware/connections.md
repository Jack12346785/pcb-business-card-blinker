# Connections

## Net List

### `VBAT`

- `BT1` positive terminal
- `SW1` input pin

### `V_SW`

- `SW1` output pin
- `R1` pin 1
- `R2` pin 1
- `R3` pin 1

### `LED1_NET`

- `R1` pin 2
- `D1` anode

### `LED2_NET`

- `R2` pin 2
- `D2` anode

### `LED3_NET`

- `R3` pin 2
- `D3` anode

### `GND`

- `BT1` negative terminal
- `D1` cathode
- `D2` cathode
- `D3` cathode

## Reference Designators

| Ref | Part |
| --- | --- |
| BT1 | CR2032 holder |
| SW1 | Momentary push button |
| R1 | LED 1 resistor |
| R2 | LED 2 resistor |
| R3 | LED 3 resistor |
| D1 | LED 1 |
| D2 | LED 2 |
| D3 | LED 3 |
